# Validation 3: 2026 trends vs YukthiX design

Lens: what leading HR, talent and assessment products ship in 2026 that YukthiX lacks. Every "missing" or "partial" below was grepped across `design/*.md` + `../spec.md` (research/ excluded) with the synonyms listed. Nothing here repeats GAP-REGISTER A–H or MARKET G1–G17.

| ID | Gap | Who ships it (examples) | Evidence (grep terms → result) | Suggested home | Size | Priority |
|---|---|---|---|---|---|---|
| T1 | **Agentic AI: HR agents that act.** AI today only answers and drafts. There is no agent framework: tool calls that create P03 requests or drafts, human-confirm step, per-agent scopes, action audit. No onboarding agent, offer-drafting agent, "close my month" payroll agent, or manager copilot ("who's on leave next week, approve all regularisations under 15 min, summarise my team"). | Workday Agents / Agent System of Record, SAP Joule agents, Oracle HCM AI agents, Darwinbox agents, Rippling AI, LinkedIn Hiring Assistant | `agentic`, `copilot\|co-pilot` → 0 hits. **P10 §A3 guardrail 5:** "tool calls are restricted to read-only governed APIs". The AI list is in P10 §A2: drafting, summaries, Q&A, anomaly hints. | P10 new §A5 "Actions & agents" (agents raise P03 requests as the user and never approve; confirm card; YX-AI rules; eval + red-team per action) + M06 manager copilot view | L | **Should** (the 2026 demo differentiator; design the action contract now so APIs stay agent-safe) |
