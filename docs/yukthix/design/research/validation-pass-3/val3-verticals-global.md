Scope: design/ P01–P19, M01–M13, T01–T08, APX-A..G, GAP-REGISTER (A–H), spec.md. Every row below was grepped with several synonyms. It is only reported if it is **missing** or **partial**, and it is not already in the GAP-REGISTER.
