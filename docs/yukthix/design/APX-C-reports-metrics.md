## 0. How to read this appendix

| Column | Values |
|---|---|
| **Wave** | Build wave (spec §4): 1 Core HR & platform · 2 Leave & attendance · 3 Payroll & statutory · 4 Lifecycle, F&F, letters, POSH · 5 Expenses, Performance, Learning, Helpdesk, Policies, Engage · 6 Differentiators (corporate cards, mobile cards) · 7 ATS & staffing desk · **PT** = Proctoring track (own track, T01) |
| **Sensitivity** | P02 classes: **Internal** · **Personal** · **Confidential** (pay, ratings, candidate data, receipts) · **Special** (tax, bank, health, BGV, case data) · **Restricted** (case-membership areas, M08; counts only outside the case) |
| **Format** | **Screen** (interactive, drill-down), **XLSX** / **CSV** / **PDF** (P09 exporters), **Statutory** (the prescribed file / form layout, owned by M03 / P07) |
| **As-on / period** | **As-on** = point in time from snapshots or ledgers (P06 dated facts); **Period** = events in a from–to range; **Both** = as-on balance with period movements |
| **Owner** | The doc that owns the source data and the report definition |

Common behaviour (not repeated per row): scope and freshness banner (YX-MET-05); viewer's P02 scope and field classes (YX-MET-03); small-group suppression for Confidential/Special breakdowns (YX-MET-04); schedule / export with audit (YX-MET-08/09); record-level reports only where the viewer may see the records. Statutory formats are generated by the owning module and are also listed in the library's **Compliance** section (P09 §4.5).
